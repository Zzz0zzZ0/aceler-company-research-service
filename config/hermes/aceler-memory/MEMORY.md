# Aceler 背调业务记忆（主档日期 2026-08-12）

## 产品主档
26个产品均启用。核心代码：FS=Fused Silica，CAA=Calcined Alpha Alumina，CCM=Caustic Calcined Magnesite，BAUXITE=Bauxite，DBM=Dead Burned Magnesite，FM=Fused Magnesite（主档英文Fused Magnesia），TA=Tabular Alumina，BFA=Brown Fused Alumina，SIC=Silicon Carbide，WFA=White Fused Alumina，MULLITE=Mullite。普通代码：CAC_PAC=Calcium Aluminate Cement & PAC，CRUCIBLE=Aluminum Silicon Ceramic Crucible，SCUP=Sprue Cup / Sprue Bowl，GE=Graphite Electrode，CORE=Ceramic Core，WAX=Wax for Precision Casting，HAC=High Alumina Cement，CA=Calcium Aluminate，CHAMOTTE=Chamotte，SPINEL=Spinel / Alumina-Magnesia，SF=Steel Fiber，SR=Steel Rod，MB=Magnesia Bricks，MGC=Magnesia Carbon Bricks，FUMED_SILICA=Fumed Silica。Hermes输出只能使用等号后的目录名称。CAC_PAC、CORE、CHAMOTTE资料状态为待完善，表内“230”是占位值，不得当作应用证据。

## 产品—工艺主路线
- 磨料制造/植砂/介质配方：BFA、SIC、WFA为主；高纯抛光或陶瓷体系可条件考虑CAA、TA。
- 耐材配料、砖、浇注料、预制件：按实际化学体系映射DBM、FM、TA、BFA/WFA、Bauxite、Mullite、HAC、CA、Spinel、CAA、CCM、SF；耐材厂自产MB/MGC是产出，不证明购买同类成品。
- 熔模铸造：FS/WFA/CAA用于型壳配方，WAX用于注蜡/组树，SCUP用于浇注系统，CRUCIBLE用于相容金属熔炼；CORE只限有陶瓷型芯/复杂内腔熔模工艺证据，普通砂芯不得映射。
- 技术陶瓷/窑具：CAA、FS、Mullite、SIC、TA、WFA按配料、成型、烧结、纯度和热震要求映射；建筑/日用陶瓷也可能有条件路线，不能仅因未公开采购而判0。
- 冶金：GE只限明确AC/DC EAF，不用于感应炉；SIC可条件用于脱氧/增硅/增碳；CA用于二次精炼/合成渣；MB/MGC及耐材原料须结合炉型和衬体部位。
- 化工配方：Fumed Silica对应胶黏剂、密封胶、硅橡胶、涂料、油墨、树脂的流变/补强；不得混同silica fume。CCM可用于耐材、电熔镁/尖晶石、陶瓷、造纸、水处理、肥料/饲料、橡胶等，但用途、级别与法规须确认。
